# TaskManagementSystem

A minimal ASP.NET Core MVC task management system built with .NET 8, Entity Framework Core, and SQLite.

## Planned Features

- Dummy login system
- User CRUD
- Task CRUD
- Task priority levels
- Task assignment to users
- Sorting by creation date and priority
- Basic validation

## Development Plan

The project is developed in phases using feature branches. Completed phases are documented in this README to support the final university report.
